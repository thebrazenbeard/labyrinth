# Model-directed Labyrinth episode — original development MVP

**Status:** Source prototype, DEVELOPMENT_ONLY. No protected graduation, pretrained-model training, independently verified examiner or live host deployment.

The text-adventure presentation is subordinate to the training system. A declared objective enters with actual readable checkpoint bytes (W0) and a separately observed baseline on approved **TRAIN-only** probes. The model-directed scene generator proposes prose, a bounded branching room graph and navigation. It gets the objective, declared skill, cycle and prior TRAIN feedback; **it does not receive the challenge prompt, answer, examiner content, or training gold**.

The chosen path leads to a real `TrainingCorridorRunner` training chamber. The learner sees a `TraineeRoomView` (prompt only), responds, and only then a trusted operator-owned `train_supervised(Challenge)` hook sees approved TRAIN supervision. The hook must return **a new local, readable, write-once weight artifact path**. The runtime hashes actual file bytes and refuses an unchanged digest or reused artifact path before recording the corridor's feedback. It neither performs a neural backward pass itself nor accepts a made-up hash as a checkpoint.

Each chamber's bounded update is a **training spark** (`TrainingSpark`): before/after SHA-256, retained artifact reference, skill, room ordinal and observed TRAIN correctness. No numerical loss is fabricated when the adapter does not supply it. Every prior retained weight/optimizer artifact is rehashed before and after each spark and before an evidence export. This prevents a later update from quietly overwriting W0 while creating a plausible new Wt, at the cost of repeated large-file reads. A future host-controlled immutable content store would be preferable for real model-scale use.

The training hook is an **external effect boundary**. Before calling it, the session enters an indeterminate state; it reopens navigation only after physical checkpoint checks, operator corridor bookkeeping and Ariadne recording all succeed. If the hook changes an artifact and then raises, the in-process episode becomes unusable for further `step()` calls or normal evidence export. **This is only an in-memory quarantine, not crash-durable write-ahead logging.** After full process failure, an operator must reconcile physical artifacts and recovery records before retrying; no automatic resumed training claim is made.

When every TRAIN chamber is complete, `complete_maze` enters the developmental Minotaur. A separate model may propose a bounded focus skill, tactic and difficulty, but a separately configured operator-run evaluator creates and scores fresh heldout/transfer evidence. The source's `evaluate_minotaur` and `face_minotaur` mathematically decide provisional PASS/FAIL/INCONCLUSIVE, enforce non-overlap with exposed TRAIN identities, and seal evaluated cases. An initial local arithmetic examiner implementation takes a separately frozen W0 predictor and computes candidate/baseline scores from fresh arithmetic problems; it does not use protected private graduation material. Failure regenerates the maze via `TrainingCorridorRunner.regenerate(journey)` with prior admitted TRAIN history, Minotaur feedback and checkpoint carried forward. The scene graph's actual topology must differ between cycles. The source-controlled training provider also changes tactics and problem semantics in response to scored TRAIN outcomes; the narrative is not itself evidence of learning.

## Original public seam

- `SagaSession(scope, learner, checkpoint, baseline_train_cases, scene_director, minotaur_director, examiner, action_budget)`
- `session.observe()` returns a `StepResult` with observation, available actions, terminal/truncated state, evidence-limited developmental status, and actual current artifact hash.
- `session.step("left" | "right" | "forward" | "back" | "look" | "train" | "face")` progresses only along model-proposed, validated paths. A bounded action budget ends runaway sessions.
- `session.ariadne_events` is a distinct **model-saga** hash-linked journal: entrance W0 and baseline counts; every visible scene topology; every physical TRAIN spark; source-measured Minotaur score totals, weakness tags and model-proposed pressure; regeneration; and exit. `verify_saga_ariadne()` checks event order, checkpoint ancestry, content and parent hashes. It intentionally does **not** change the existing toy Ariadne schema.
- `session.save_receipt_new(local_path)` writes one JSON receipt exclusively, including locally recoverable artifact references and journal-head SHA-256, then strictly rereads/validates it. The local checkpoint paths can be sensitive and should not be published. A complete attacker-controlled rewrite can recompute hashes: this is **not** an independent cryptographic witness or persistent process-resume engine.
- Exported receipts distinguish `IN_PROGRESS`, `TERMINATED`, and `TRUNCATED`. A terminal or truncated receipt must have a valid terminal Ariadne event; reports cannot be emitted while the trainer's physical effect is indeterminate.
- `SceneDirector.propose_world(SceneRequest) -> WorldProposal` supplies 4–8 accessible scenes; the entrance branches to at least two distinct nodes, all nodes must be reachable, and one chamber has no outgoing navigation. Invalid, disconnected, answer-injection and unchanged-regenerated topology proposals are refused.
- `SagaLearner.predict(prompt)` and `train_supervised(source_owned_train_case) -> CheckpointPaths` run as trusted local adapters. They must not be loaded from untrusted game text.
- `MinotaurDirector.propose_pressure(ExamPressureContext) -> ExamPressure` is a model proposal, not a grader. `DevelopmentExaminer.assess(ExaminerRequest, predict_only_callback)` is a separate operator-owned scoring seam. Its per-attempt seed is domain-separated from TRAIN routing and not passed to the scene or pressure models.

## Checkpoint and qualification boundaries

- Entrance file SHA-256 is recomputed from actual bytes; optional optimizer file receives a separate SHA-256. With no optimizer file the explicitly reported status is `WEIGHTS_ONLY_CONTINUITY`. Even when an optimizer file exists, scheduler/RNG and restart fidelity are **not** verified by this module.
- Unique artifact paths and changed weight hashes after TRAIN are required. A self-controlled trainer could still write unrelated bytes and pass; changed bytes **do not prove learning**, and file hashes lack external anti-rollback anchoring. Rehashing all historical files scales poorly with checkpoints the size of Qwen and must be replaced or optimized before serious deployment.
- An operator's baseline TRAIN probes are a pre-TRAIN skill measurement, **not** the private/heldout Minotaur baseline. The developmental examiner separately compares candidate versus frozen W0 responses on its own unseen split. Both are source-level observations without independent custody.
- The narrative and model-proposed pressure never receive hidden gold; the trusted Python operator does. Python adapters are **not sandboxed**.
- The built-in live corridor and included mathematical local examiner are arithmetic-only. There is no real pretrained local inference or HF/LoRA training adapter in this slice, no cross-process rehydration of the journey, no structural transfer qualification, and no independently signed graduation.
- The optional Syllabus curriculum bridge, neural successor contracts and any TextWorld-style external engine are separate; this module has **zero new dependencies** and copies no third-party code. The original room-proposal API intentionally differs from TextWorld's to keep the game overlay distinct from examined learning.
- Experimental **weight-space programming** proposals inspired by [Takehi et al., November 2, 2026](https://rikiyat.github.io/blog/weight-space-programming/) are isolated in `labyrinth/weight_space_spark.py`. Their W0-bound sparse coordinate descriptions are **not applied, trained or scored** here. The authors' finding that a sparse edit remedied Qwen3.5-0.8B repetition does not imply that applying the same edits to Vera's 4B model would work.

## Verified local checks

`python -m unittest -v tests.test_model_saga_runtime` exercises deterministic model-proposed topology, branching actions, real file-hash transitions, TRAIN scoring via the repository runner, failed developmental Minotaur regeneration, successful bounded internal development on the next cycle, altered exam pressure, fresh split seeds, action-budget truncation, invalid actions, leaked answer rejection, and missing/unchanged artifact refusal.

This test uses a deliberately simple file-mutating stand-in learner for deterministic mechanics; it is **not a neural training benchmark**. Only a separate measured local-model execution can establish the intended genuine model adaptation.
